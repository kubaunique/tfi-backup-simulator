# Резервное копирование

Учебный проект TFI для групп SCA-24. Python 3.10 или новее.

## Файлы

- `TFI01_backup_simulator.py`

## Запуск

Скачайте репозиторий через Code → Download ZIP и распакуйте его. Откройте терминал в папке проекта. На Windows, если команда python недоступна, используйте py вместо python.

Сторонние библиотеки не требуются.

```text
python TFI01_backup_simulator.py
```

## Демонстрация

Создайте папку data с двумя учебными файлами. Запустите программу из каталога проекта, нажмите Enter для выбора data. Проверьте файлы в backup/дата-время. Для демонстрации восстановления удалите только учебный файл из data и скопируйте его из резервной копии.

## Особенности и изменения

Запрещено размещать резервную копию внутри исходной папки или в самой исходной папке. Время включает микросекунды для повторных запусков.

Проверено 04.11.2026 на Windows с Python: запуск, штатные сценарии и основные ошибочные входные данные. Общая проверка шести проектов: 10 тестов, все прошли. Для паролей используйте только вымышленные примеры.

## Задание команде

Подготовьте 6–8 слайдов и защиту на русском языке: назначение программы, входные данные, одна ключевая функция и запуск примера. Каждый участник объясняет свою часть. Писать программу с нуля не требуется.
